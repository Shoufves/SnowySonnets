## 进程管理

- `ps aux` 查看进程
- `top` 实时查看系统状态
- `kill` 结束进程

## 服务管理

使用 `systemctl` 管理服务：

```bash
systemctl status nginx
systemctl restart nginx
```

## 日志

常见日志位于 `/var/log/` 目录。
